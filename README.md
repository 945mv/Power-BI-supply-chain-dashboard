# Samsung Supply Chain & Logistics Dashboard

## Project Overview

This project is an interactive Supply Chain and Logistics Dashboard developed using Microsoft Power BI. The dashboard provides a consolidated view of key supply chain metrics and enables analysis of supplier performance, inventory, shipments, and customer revenue.

The dashboard is designed to present business information through interactive KPIs and visual reports for easier monitoring and analysis.

## Objective

The objective of this project is to transform supply chain data into meaningful visual insights using Power BI.

The dashboard focuses on analyzing:

- Overall revenue and profitability
- Supplier lead time
- Inventory value by product
- Shipment delays by carrier
- Customer-wise revenue
- Order and shipment quantities
- Delivered quantity
- Perfect order performance

## Dashboard Overview

The dashboard provides an overview of four major areas:

### 1. Supplier

The Supplier section provides supplier-related information and includes analysis of average lead time by supplier.

### 2. Inventory

The Inventory section focuses on inventory information and displays inventory value by product.

### 3. Shipment

The Shipment section provides shipment-related metrics and analyzes total delays by carrier.

### 4. Customer

The Customer section presents customer-related information and compares total revenue generated by different customers.

The dashboard contains visual analysis for:

- Average Lead Time by Supplier
- Inventory Value by Product
- Total Delay by Carrier

These visualizations help compare different entities and identify variations in supplier lead time, inventory value, shipment delays, and customer revenue.
